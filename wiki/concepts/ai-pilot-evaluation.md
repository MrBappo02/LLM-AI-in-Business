# AI pilot evaluation

Testing one AI use on the firm's own historical cases against a pass level written down before the test starts, then deciding whether to stop, use or build further. It replaces vendor accuracy claims with the firm's own measurement.

## What the sources say

- Write the pass level down before you start. For AI quoting it is: error no worse than the human quote, less time per quote, payback within one year. [[2026-10-05-aibs-handbook-themes-1-2]]
- Build a test set of 20–30 past in-house parts with quoted and actual hours and cost. Compare the AI estimate, the human quote and the actual cost with the estimator. Then decide: stop, use, or build an own model with a knowledge centre. [[2026-10-05-aibs-handbook-themes-1-2]]
- Published accuracy figures come from other firms' parts, so the firm's own evaluation phase is the real check. [[2026-10-05-aibs-handbook-themes-1-2]]
- Only office assistants have measured gains, and they are small (2.8% of work hours, relayed from Humlum & Vestergaard, 2025). [[2026-10-05-aibs-handbook-themes-1-2]]
- For RFQ drafting: compare the AI's fields with what the estimator entered on 50 past RFQs, count errors per field (watch tolerances), and set the pass level first. Trust the tool only as far as that test shows. [[2026-09-24-aibs-handbook-trust-ai-safety]]
- Evaluation should cover dependency as well as performance: compare time saved, quality, where data goes, and what happens if the vendor changes price or terms. [[2026-10-12-aibs-handbook-geopolitics]]

Confidence note: all three sources are chapters of the same course handbook, so 0.75 is the ceiling.

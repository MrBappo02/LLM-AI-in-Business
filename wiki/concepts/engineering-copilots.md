# Engineering copilots

Generative AI assistants built into automation engineering software, such as the tools used to program PLCs and configure machines. The engineer describes a task in natural language and the copilot generates or changes the project itself. It is the same pattern as [[ai-assistants-in-cad]], applied to control and automation engineering rather than 3D design.

## What the sources say

- Acting, not suggesting: Siemens says its Engineering Copilot TIA carries out complex engineering tasks by generating and modifying project elements itself, unlike traditional tools that only offer suggestions. [[2025-12-10-siemens-engineering-copilot-tia]]
- Tasks covered: code generation and testing, visualisation development, project localisation, workflow automation, configuration support for hardware such as drives, and in-app guidance. [[2025-12-10-siemens-engineering-copilot-tia]]
- Each capability can be switched on or off by the user. [[2025-12-10-siemens-engineering-copilot-tia]]
- Delivery: a managed (vendor-hosted) service attached to existing engineering software (TIA Portal V19 and V20), in beta with pilot customers. [[2025-12-10-siemens-engineering-copilot-tia]]
- Claimed benefit: engineers are freed from repetitive work for higher-value tasks. A pilot machine builder reports time saved, better quality and faster machine delivery to its customers, without figures. [[2025-12-10-siemens-engineering-copilot-tia]]

## Caveat on the evidence

The only source so far is a short trade-press report of a vendor announcement (Siemens) with a pilot customer's testimony. It gives no accuracy figures or time savings, and does not say how engineers review what the copilot produces. Confidence stays at 0.7 and cannot rise above 0.75 until an independent source reports how such copilots perform.
